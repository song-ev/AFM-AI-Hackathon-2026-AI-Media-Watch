# Подготовка к GitHub

## Что изменено

- README переписан на русском по фактической структуре проекта и заданию хакатона.
- Добавлены безопасные `.env.example` для backend и frontend.
- Расширен `.gitignore`; добавлены Docker ignore-файлы, чтобы локальные секреты не попадали в образы.
- В зависимости добавлены SDK `openai` и `anthropic`, которые импортирует существующий LLM-клиент.
- Compose передаёт `.env` в backend/workers, запускает отдельную очередь эфиров и планировщик.
- В Docker добавлены языковые пакеты OCR; frontend использует `npm ci` и существующий lockfile.
- Уточнена документация развёртывания.

Скопированы отслеживаемые Git исходники из исходного проекта, кроме стандартных весов `yolov8n.pt`. Локальный `.env`, `.venv`, `media/`, служебные файлы Celery и старая `.git` не переносились. Файлы весов скачиваются или предоставляются отдельно. Исходный проект не изменён. Новая копия не сохраняет авторство коммитов исходной истории; сведения о команде нужно добавить отдельно.

## Проверка перед публикацией

Фактические результаты перечислены в `VALIDATION.md`. Выполнены автоматические backend-тесты и проверки frontend. Полный сценарий с внешними AI-моделями и сборка Docker требуют отдельного окружения. Наличие исходного кода не означает готовность к production.

При проверке исправлены конфликт ESLint/Next.js и устаревший `next lint`, синхронизация состояния и refs в React-компонентах, а также проверка относительного пути видео в существующем тесте. Тест дополнительно проверяет хеш содержимого сохранённого файла. Добавлен изолированный профиль `ai_media_watch.settings.test`.

Внешние API и endpoint очищены; инструкции перенесены в README. Проверка чувствительной информации описана в [SECURITY_REVIEW.md](SECURITY_REVIEW.md). Тестовые окружения и сборки в копию не включены.
