# Мониторинг эфиров (live) — TikTok / YouTube / Instagram

Реал-тайм проверка трансляций: система захватывает идущий эфир короткими
чанками (по умолчанию 30 c), регистрирует каждый чанк как видео, прогоняет через
Stage-1 screening и поднимает **LiveAlert** в момент срабатывания — то есть
нарушение ловится, пока стрим ещё идёт.

Реализация: `ingestion/services/live_capture.py` + задача
`ingestion.tasks.monitor_live_session`. UI: вкладка **«Эфиры»** на странице
«Анализ». Технически: `yt-dlp` резолвит манифест трансляции → `ffmpeg` пишет
чанк (`-c copy`, без перекодирования) → существующий пайплайн.

## Что требуется от вас — по платформам

### YouTube Live — ✅ почти ничего
- Достаточно ссылки на трансляцию (`youtube.com/watch?v=…` или `/live`).
- Cookies нужны только для приватных/региональных трансляций.
- **От вас:** ничего для публичных эфиров.

### TikTok Live — ⚠️ нужен cookies (главный акцент)
- TikTok отдаёт live-манифест только аутентифицированной сессии.
- **От вас:**
  1. **cookies-файл** залогиненного TikTok-аккаунта (Netscape `cookies.txt`,
     экспорт расширением браузера). Путь в `.env`:
     ```
     YTDLP_COOKIES_FILE=/secure/path/tiktok_cookies.txt
     ```
  2. Прямая ссылка вида `https://www.tiktok.com/@username/live` (или просто
     `@username`, когда аккаунт в эфире).
  3. При долгом/множественном мониторинге — **прокси с ротацией** (резидентские/
     мобильные), чтобы не словить бан по IP:
     ```
     YTDLP_PROXY=http://user:pass@host:port
     ```
- Аккаунт для cookies лучше «прогретый» (не свежерегистрированный) и не жалко,
  если попадёт под ограничения.

### Instagram Live — ⚠️ обязательны cookies, самый хрупкий
- **От вас:** cookies-файл залогиненного Instagram-аккаунта (тот же
  `YTDLP_COOKIES_FILE` или отдельный — скажите, разведу по платформам) + желательно
  прокси. Instagram агрессивно ограничивает автоматизацию; стабильность ниже, чем
  у TikTok/YouTube.

## Сводка: минимум для запуска

| Платформа | Минимум от вас | Для масштаба |
| --------- | -------------- | ------------ |
| YouTube   | ссылка на эфир | — |
| TikTok    | cookies + ссылка `@user/live` | + прокси с ротацией |
| Instagram | cookies + ссылка | + прокси |

Без cookies сразу работает **YouTube Live**. Дайте cookies-файл (и, по желанию,
прокси) — включу TikTok и Instagram. Если хотите разные cookies на разные
платформы, скажу, как добавить `YTDLP_COOKIES_TIKTOK` / `_INSTAGRAM`.

## Параметры сессии
- `chunk_seconds` (10–120) — длина чанка; меньше = быстрее алерт, больше = меньше
  нагрузка.
- `max_chunks` — предохранитель от бесконечного захвата (по умолчанию 120).
- Остановка вручную: кнопка **«Стоп»** в UI или `DELETE /api/ingestion/live/<id>/`.
