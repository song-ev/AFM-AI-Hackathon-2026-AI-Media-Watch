# Проверка чувствительной информации

Проверена подготовленная копия для GitHub, включая исходники, документацию, шаблоны конфигурации и lockfile. Проверка выполнена 3 октября 2026 года.

- Сопоставлены полные чувствительные значения и отдельные компоненты адресов/паролей исходного `.env` с публикационными файлами. Совпадений не найдено; значения не выводились в отчёт.
- Выполнен поиск типичных токенов провайдеров, GitHub/AWS/Google, JWT, приватных ключей и облачных строк подключения с учётными данными. Подозрительных совпадений не найдено.
- `.env`, cookies, локальные базы, медиа, веса моделей, виртуальные окружения, node_modules и .next исключены из копии и архива. Создана новая пустая Git-история; история исходного репозитория не публикуется.
- Удалены готовые LLM-endpoint и имена моделей из настроек/шаблонов. Для обоих SDK обязательны собственные ключ, endpoint и модель. При неполной конфигурации запрос не отправляется.
- Удалён преднастроенный сервер карт; URL/атрибуцию пользователь задаёт самостоятельно. Иконки карты поставляются локально из зависимости Leaflet.
- Удалён фиксированный demo-пароль: команда генерирует случайный при каждом запуске.
- Сообщения об ошибках LLM не включают сырой текст исключения провайдера, который может содержать адрес запроса или фрагменты учётных данных.

В репозитории остаются демонстрационные локальные параметры PostgreSQL/Django, искусственные тестовые данные, публичные ссылки на хакатон/соцсети и источники зависимостей. `NEXT_PUBLIC_*` доступны посетителям сайта: секретные ключи туда помещать нельзя. Конкретная инструкция подключения собственных сервисов находится в README.

Это проверка публикационного содержимого, а не полный аудит безопасности приложения. Исходные локальные секреты не изменялись; если они ранее публиковались отдельно, их необходимо отозвать у соответствующего провайдера.
